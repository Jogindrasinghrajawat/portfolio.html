# portfolio.html

A minimal, responsive personal portfolio website built with plain HTML, CSS, and optional JavaScript. This repository contains the source files for a static portfolio site you can deploy via GitHub Pages or any static hosting service.

Live demo: https://jogindrasinghrajawat.github.io/portfolio.html

## Features
- Clean, responsive layout for desktop and mobile
- Sections for About, Projects, Skills, and Contact
- Easy to customize and extend
- No build step required — purely static files (HTML/CSS/JS)

## Technologies
- HTML5
- CSS3 (Flexbox / Grid)
- Optional: vanilla JavaScript for interactivity
- Optional: GitHub Pages for hosting

## Getting Started (Local)
1. Clone the repository:
   git clone https://github.com/Jogindrasinghrajawat/portfolio.html.git
2. Open `index.html` in your browser, or serve locally with a simple HTTP server:
   - Python 3: `python -m http.server 8000`
   - Node (http-server): `npx http-server`
3. Visit http://localhost:8000 to view the site.

## Customization
- Replace content in `index.html` (name, bio, project descriptions).
- Update styles in CSS files (e.g., `styles.css`).
- Replace or add images in the `assets/` folder.
- Add projects by duplicating the project card/section markup.

## Deployment (GitHub Pages)
1. Push changes to the `main` branch (or use a `gh-pages` branch).
2. In the repository Settings → Pages, enable GitHub Pages and select the branch/root.
3. Your site will be available at `https://<your-username>.github.io/portfolio.html/`.
