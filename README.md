A modern, responsive, single-page portfolio website designed with a focus on **UI/UX**, **Dark Mode**, and **Glassmorphism**. Built using pure HTML, CSS, and Vanilla JavaScript with no external framework dependencies.

## ✨ Features

- **🎨 Modern UI:** Deep dark mode with a "Glassmorphism" (frosted glass) aesthetic.
- **📱 Fully Responsive:** seamless experience across Desktop, Tablet, and Mobile.
- **⚡ Performance:** Single-file architecture (HTML/CSS/JS bundled) for lightning-fast load times.
- **✨ Animations:**
  - **Scroll Reveal:** Elements fade in and slide up as you scroll.
  - **Micro-interactions:** Hover effects on cards and buttons.
  - **Background Glow:** Subtle mesh gradient background.
- **typography:** Uses the modern 'Outfit' font from Google Fonts.
